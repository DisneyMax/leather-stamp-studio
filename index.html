Laser cut registration

For solid debossing stamps. Turning this on grows the backing if needed and keeps the artwork the same size. The cross and ring go on scrap outside the finished cut.

Cut offset starts at the outside of the artwork and any decorative border. Mark clearance starts at the cut line and ends at the nearest mark edge.

Advanced settingsDepth, artwork adjustments, and mesh detail

The defaults are our tested starting values. Adjust only if you need a different impression depth, clearance or edge detail.

The embossing face clears the holder rim by 1.5 mm. Use a cavity depth of 0.2–2.5 mm.

Positive values thicken the artwork edges. Negative values thin them. Large adjustments can close holes or remove thin details.

Mesh detail controls

Smaller accuracy values preserve more detail but increase mesh complexity. Contour base uses a convex silhouette. Edge recovery may reduce the entire bevel width; the applied value is shown in validation details.

First stamp guide
  1. Start with the paw print. Choose Use example paw print and leave Fit to base selected. For your own SVG, use vector fills and solid strokes. Convert text and dashed strokes to outlines in your vector editor.
  2. Choose the impression. Start with Debossing (raised stamp) to press the paw into the leather. Choose Embossing (recessed die) for a raised impression. Keep Mirror artwork for stamping on for artwork that should read correctly on the leather. If the SVG is already reversed, turn it off.
  3. Review the design. Open 2D Design to check placement and holes. Turn on Check small features for estimated trouble spots. If you adjust thickness, use Show thickness changes to see what was added or removed.
  4. Generate and inspect. Select Generate 3D stamp, check the 3D preview, and select Download STL once the mesh passes validation. In Bambu Studio, import in millimeters, verify the dimensions, and inspect the sliced layers for missing details or filled holes. Test the printed stamp on a leather offcut.
  5. Keep your work. Use Save project JSON below Download STL to save your SVG and settings. Use Load project JSON to resume later.
