Advanced settingsDepth, artwork thickness, and mesh detail

The defaults are our tested starting values. Adjust only if you need a different impression depth, clearance or edge detail.

+ thickens details · − thins them · 0 keeps your SVG unchanged. The slider moves in 0.05 mm steps. Type a value for finer control. A strong adjustment can close small holes or remove thin details.

Mesh detail controls

Smaller accuracy values preserve more detail but increase mesh complexity. Contour base uses a convex silhouette. Edge recovery may reduce the entire bevel width; the applied value is shown in validation details.

Projects & technical checksSave, load, and validation notes

Projects include SVG artwork and all size and quality settings, stored locally in your downloaded JSON file.

Final checks

V3.1 validates boundary edges, non-manifold edges, inconsistent face orientation and degenerate triangles before enabling STL export. Mesh checks cannot guarantee slicer compatibility or print strength. Import STL into Bambu Studio as millimeters. Recessed dies may require a matching positive die to produce a raised leather impression.
